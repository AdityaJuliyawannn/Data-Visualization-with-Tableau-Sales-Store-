**Data Visualization with Tableau (Sales Store)**
Overview
This project presents an interactive data visualization dashboard built using Tableau to analyze sales performance across different store locations. The dashboard provides insights into key business metrics such as sales, profit, and customer trends to support data-driven decision making.
