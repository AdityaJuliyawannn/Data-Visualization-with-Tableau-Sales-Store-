# Data-Visualization-with-Tableau-Sales-Store-
This project presents a data visualization dashboard built using Tableau to analyze sales performance across store locations. The dashboard highlights key metrics such as total sales, profit, and customer trends to support data-driven decision making.

- How to Use
  
1. Open the Tableau dashboard file (.twbx)
2. Explore the interactive filters (region, category, date)
3. Analyze the visualizations to gain insights
